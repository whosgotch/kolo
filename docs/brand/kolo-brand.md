# Kolo — brand spec

Authoritative rules for anything visual. Tokens live in `kolo-tokens.css` /
`kolo-tokens.json`. The mark is generated by `ring.ts` — never hand-draw it,
never trace it, never paste a copy of the ASCII output into a component.

## Mark

One object: a circle with a second circle subtracted, offset up and right.

- outer radius `r`, inner radius `0.71r`
- inner centre offset `+0.129r` on x, `-0.129r` on y (up and right)
- ring weight runs `0.10r` (thin, top right) → `0.4724r` (thick, lower left)
- clear space: `0.25r` on every side; nothing enters it
- orientation is fixed — thin end top right. Rotation only as animation, and
  only while work is actually running; it returns to rest.
- minimum size: vector 16px; ASCII 12 rows. Below 12 rows use the vector mark.

Never render the ring as a constant-width outline. The taper is the identity.

## Ramp

The mark is a rule, not an asset. Per character cell, sample coverage and ring
thickness, map to a 10-step ramp:

```
" .:-=+*#%@"
```

`floor 0.42`, thickness gamma `0.85`, supersample 3–4× per cell. Cell aspect
(width/height) is `0.602 / 1.17` for JetBrains Mono at line-height 1.17 —
`cols = round(rows / aspect)`. Get this wrong and the ring goes oval.

**Accent rule:** only `%` and `@` take brass. Everything else is chalk on void
or void on chalk. Colour is earned by density. No gradients, no second accent.

## Colour

| token | hex | role |
|---|---|---|
| void | `#101314` | ground, ink on light |
| graphite | `#1C2123` | raised surface |
| slate | `#6E7673` | secondary text, idle state |
| chalk | `#E7E9E4` | surface, ink on dark |
| patina | `#2C6F62` | structure: links, focus, selection, cursor |
| brass | `#D9A441` | signal: active agent, ramp top |
| brass-ink | `#9C6C15` | brass as text on light surfaces (contrast) |
| fail | `#A63D2E` | failed state only |

Dark is the default ground; light is the exception. State vocabulary is exactly
four: slate = idle, brass = running, patina = done, fail = failed. Do not add a
fifth. Do not use brass for emphasis, hover, or branding fill — it means "this
is the one currently working".

## Type

- **JetBrains Mono** (400/500/700) — wordmark, labels, numbers, status, data,
  anything the machine says.
- **Archivo** (400/500/600) — prose a person reads at length.

Never set body copy in mono to look technical. Wordmark: lowercase always,
weight 500, letter-spacing `0.06em`. Never bold, capitalised, or italic.

In the horizontal lockup, keep a 1px slate divider between mark and wordmark —
without it the pair reads as "okolo".

## Voice

Reports, does not narrate. Sentence case, active verbs, present tense. No
exclamation marks, no apologies, no emoji. The product never says "I" — it is
not one of the agents.

```
Ring closed. 4 of 7 finished, 1 failed on tests.
Take the ring with tab.
No session yet. Start one with kolo run.
```

Not: "Oops! Something went wrong", "I've gone ahead and…", "Nothing to see here".

## Don't

- redraw the ring as a constant-width outline
- rotate, mirror, or skew the resting mark
- place the mark on a photo or gradient
- add a second colour to the ramp
- set prose in monospace
- use brass for anything other than the active agent
